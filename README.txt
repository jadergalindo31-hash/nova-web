# Verde Nova — sitio web de muestra

## Cómo abrir
1. Descarga y extrae el ZIP.
2. Abre `index.html` en tu navegador, o usa Live Server desde Visual Studio Code.

## Cómo publicar en GitHub Pages
1. Crea un repositorio público en GitHub.
2. Sube `index.html` a la raíz del repositorio.
3. Entra en Settings → Pages.
4. En Build and deployment, elige Deploy from a branch.
5. Selecciona `main` y `/ (root)`, guarda y espera a que GitHub genere el enlace.

## Personalización
- Cambia el nombre “Verde Nova” y los textos directamente en `index.html`.
- El correo de contacto es un ejemplo (`hola@verdenova.example`); reemplázalo por uno propio antes de publicar.
- Los proyectos de la sección “Ideas en movimiento” son conceptos ficticios.
- Esta demo no tiene backend, formulario, analítica ni cookies de seguimiento.

## Seguridad
La página es estática y no procesa ni almacena datos personales. No añadas contraseñas, tokens ni claves privadas al HTML o JavaScript.
